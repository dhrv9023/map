"Theoretically, this is O(N) time and O(N) space. The 7 Pillars of Silicon Empathy

Pillar 1: Memory Coalescing & Contiguous Layouts (SoA vs. AoS)

Hardware Memory

Structure of Arrays enables 32 SIMD/CUDA lanes to load consecutive 4-byte floats in a single coalesced 128-byte DRAM transaction.

The Trap: Array of Structures (struct Particle { float x,y,z; } p[N]) causes strided uncoalesced access (32 transactions instead of 1).

Pillar 2: Bitwise Arithmetic as a First-Class Language

Bit Manipulation

32-bit registers represent thread execution masks (__activemask). Alignment, bit-reversal, and popcount are production primitives.

(addr + 63) & ~63 • 64-byte cache line alignment
(n > 0) && ((n & (n - 1)) == 0) • Power-of-two check
x & (power_of_2_size - 1) • Fast branchless modulo
x & -x • Lowest set bit (Fenwick trees / sparse indexing)
__builtin_popcount(mask) • Active warp thread count
