Total 42 Patterns

#1 Complexity calibration

Pre-code decision
Trigger: Any problem with 'efficient' + a large n stated
Core Idea: Derive acceptable TC from n BEFORE designing anything; eliminate approaches that cannot fit
Structures: None - pure reasoning
🟢 AI-Infra / Hardware: Latency budgets; SLO thresholds; batch-size selection

#2 Frequency/counting + hashing

O(n) time, O(k) space
Trigger: 'anagram','k most frequent','duplicates','count of','appears more than once'
Core Idea: Replace repeated scans with one pass building counts; hash the KEY that captures the invariant
Structures: hash map, count array, bucket array
🟢 AI-Infra / Hardware: Hot-key detection, metric counters, histogram-based alerting

#3 Prefix/suffix reasoning

O(n) build, O(1) query
Trigger: 'subarray sum','range query','product except self','subarrays satisfying condition'
Core Idea: Precompute cumulative info so any range is O(1); prefix+hash converts a condition into a lookup
Structures: prefix array, hash map (prefix -> count or prefix -> first-index)
🟢 AI-Infra / Hardware: Rolling aggregates, cumulative metrics, event-log windows

#4 Two pointers (opposite ends)

O(n) after sort
Trigger: sorted or sortable input; 'pair/triplet sums to'; 'maximum area between'
Core Idea: Move the pointer that provably cannot improve the answer; prove no valid pair is skipped
Structures: two indices into the same array
🟢 AI-Infra / Hardware: Merging sorted shard scans; two-way join on sorted data

#5 Two pointers (same direction / read-write)

O(n) time, O(1) space
Trigger: 'in place','remove elements','partition','k-th from end'
Core Idea: Separate a slow write-index from a fast read-index; maintain a region invariant
Structures: two indices, optional dummy node for lists
🟢 AI-Infra / Hardware: In-place buffer compaction; zero-copy stream rewriting

#6 Sliding window (variable)

O(n)
Trigger: 'longest/shortest subarray/substring satisfying condition'; contiguous required
Core Idea: Grow right pointer; shrink left while invalid. ONLY valid when extending cannot repair a violation.
Structures: hash map or count array for window contents, two indices
🟢 AI-Infra / Hardware: Rate limiting, windowed quotas, token bucket

#7 Sliding window + counting

O(n) or O(n | |alphabet|)
Trigger: 'at most K distinct','replace at most k characters','subarrays with exactly k'
Core Idea: Track frequency inside the window; exactly(K) = atMost(K) - atMost(K-1)
Structures: hash map, freq array, maxFreq variable
🟢 AI-Infra / Hardware: Cardinality-bounded caches; distinct-key windows in streaming analytics

#8 Binary search (index)

O(log n)
Trigger: sorted array; 'first/last position'; 'O(log n) required'
Core Idea: Maintain a half-open invariant (lo<=answer<hi); shrink systematically; no templates
Structures: sorted array (or implicit sorted space)
🟢 AI-Infra / Hardware: SSTable lookups, sorted offset indexes, version search

#9 Binary search on answer

O(n log(answer_range))
Trigger: 'minimize the maximum','maximize the minimum','minimum capacity/speed/time'; large answer range
Core Idea: Search the ANSWER SPACE with a monotone feasible(x) predicate; 3 validity conditions must hold
Structures: feasibility predicate function + binary search loop
🟢 AI-Infra / Hardware: Capacity planning, autoscaling, SLO fitting, quota allocation

#10 Sort + linear scan (preprocessing)

O(n log n)
Trigger: 'intervals','pairs','sorted input assumed'; O(n log n) acceptable
Core Idea: Sorting creates a monotonicity you can then exploit with a single greedy pass
Structures: sort + one or two pointers or a heap
🟢 AI-Infra / Hardware: Log compaction ordering, sorted shard merging, LSM-tree compaction

#11 Interval / sweep line

O(n log n)
Trigger: 'overlapping intervals','maximum concurrent events','resources needed at peak'
Core Idea: Convert intervals to +1/-1 events and sweep; or maintain a min-heap of active end times
Structures: sorted events array, min-heap of end times
🟢 AI-Infra / Hardware: Concurrent resource counting (GPU/CPU slots), admission control

#12 Monotonic stack

O(n) amortized
Trigger: 'next greater/smaller element','previous smaller','span','largest rectangle'
Core Idea: Keep a monotone stack; each pop resolves one answer; total pops <= n -> amortized O(n)
Structures: stack of indices (not values)
🟢 AI-Infra / Hardware: Monotone-break detection in metric streams, backpressure onset

#13 Monotonic deque

O(n)
Trigger: 'maximum/minimum of every window of size k','sliding extremum','windowed DP'
Core Idea: Maintain a deque of indices in monotone order; evict out-of-window and dominated candidates
Structures: deque of indices
🟢 AI-Infra / Hardware: Rolling max latency, watermarks, windowed DP in schedulers

#14 Heap / top-K / streaming extremum

O(n log k) or O(log n) per operation
Trigger: 'k largest/smallest','median of stream','schedule next available resource'
Core Idea: Partial order is enough; a heap gives the extreme in O(log n); heapify is O(n)
Structures: min-heap or max-heap; two heaps for median; heap of (key, cursor) for merge
🟢 AI-Infra / Hardware: Top-K hot keys, p99 estimation, eviction candidate selection, priority scheduling

#15 Greedy invariants

O(n log n) typically
Trigger: 'maximum number of','minimum steps','locally safe choice'; often after sorting
Core Idea: Prove by exchange or staying-ahead that the local choice is in some optimal solution
Structures: sort + counters, heap, or simple scan
🟢 AI-Infra / Hardware: Admission control, retry budgets, checkpoint placement

#16 Design / structure composition

O(1) per operation
Trigger: 'implement X with O(1) get/put/delete','LRU','LFU','getRandom'
Core Idea: Compose two structures so each required operation is O(1)/O(log n); API dictates structures
Structures: hash map + doubly linked list (LRU), freq buckets + maps (LFU), array + index map (getRandom)
🟢 AI-Infra / Hardware: Page/feature/embedding caches, KV stores, rate limiters, versioned stores

#17 Bit manipulation

O(1) per mask op
Trigger: 'subset of at most 20 items','XOR','without extra space','count bits','feature flags'
Core Idea: A bitmask is a tiny set with O(1) set operations; XOR cancels pairs; use popcount for size
Structures: integer masks, popcount, __builtin_ctz
🟢 AI-Infra / Hardware: Bitmaps, feature flags, GPU lane/warp masks, bloom filter ops

#18 Tree recursion (contract-first)

O(n)
Trigger: 'depth','balanced','path sum','subtree property','lowest common ancestor'
Core Idea: Define exactly what the function returns for a subtree; write it in English before coding; then trust it
Structures: recursion, call stack, optional memoisation
🟢 AI-Infra / Hardware: Recursive dependency evaluation, nested config resolution

#19 Tree DP (post-order)

O(n)
Trigger: 'max path','rob houses in tree','distribute coins','max sum with no adjacent'
Core Idea: Combine children's return values at the parent; return one value upward; update global answer separately
Structures: recursion + tuple return (gain upward, answer updated)
🟢 AI-Infra / Hardware: Aggregating metrics up a topology/ownership tree

#20 BST ordering

O(h) per operation
Trigger: 'validate BST','k-th smallest in BST','BST range queries'
Core Idea: In-order traversal is sorted; propagate valid range (lo, hi) top-down instead of comparing parent-child
Structures: recursion with range bounds, iterative inorder stack
🟢 AI-Infra / Hardware: Ordered indexes, range scans, B-tree node invariants

#21 BFS levels / shortest hops

O(V+E)
Trigger: 'minimum steps','level order','nearest X','spread from source'
Core Idea: First visit = shortest distance; seed all sources at level 0 for multi-source; expand in layers
Structures: queue, visited set/array
🟢 AI-Infra / Hardware: Hop counts, blast-radius analysis, BFS-based propagation

#22 Graph DFS / components

O(V+E)
Trigger: 'islands','connected components','clone graph','cycle detection','safe states'
Core Idea: Explore exhaustively; component identity or cycle colour (white/grey/black) is the output
Structures: recursion or explicit stack, visited array, colour array for directed cycles
🟢 AI-Infra / Hardware: Topology discovery, cluster membership, service-graph crawling

#23 Union Find (DSU)

O(alpha(n)) amortized per op
Trigger: 'connected components that grow','merge groups','edges arrive incrementally','redundant edge'
Core Idea: Maintain disjoint sets with path compression + union by size for near-O(1) amortized ops
Structures: parent array + size array
🟢 AI-Infra / Hardware: Cluster membership, shard grouping, entity dedup, dynamic edge-stream connectivity

#24 Topological sorting

O(V+E)
Trigger: 'prerequisites','build order','dependency resolution','detect cycle in directed graph'
Core Idea: Remove in-degree-0 nodes repeatedly (Kahn); or DFS with 3 colours; cycle = fewer than n emitted
Structures: in-degree array + queue (Kahn), or recursion + colour array (DFS)
🟢 AI-Infra / Hardware: DAG job scheduling, ML pipeline orchestration, build dependency resolution

#25 Dijkstra / weighted shortest path

O(E log V)
Trigger: 'minimum cost/time path','non-negative edge weights','network delay'
Core Idea: Greedily finalize the closest unfinished node; the popped distance is final (non-negative weights only)
Structures: min-heap of (distance, node) + dist array
🟢 AI-Infra / Hardware: Latency-aware routing, cost-based placement, weighted service graphs

#26 State-space BFS/Dijkstra

O(states * transitions)
Trigger: 'minimum moves with a resource budget','compound state','configuration reachability'
Core Idea: Nodes are FULL STATES (not just position); encode the state tuple; visited keyed on the complete state
Structures: queue or min-heap, visited set of encoded state tuples
🟢 AI-Infra / Hardware: Scheduler/config state exploration, rollout planning, deployment state machines

#27 Backtracking + pruning

Exponential with pruning factor
Trigger: 'all combinations/permutations/partitions','place N items with constraints'
Core Idea: Choose, explore, unchoose; the real skill is pruning branches that cannot lead to valid solutions
Structures: recursion, path array, bitmasks for O(1) constraint checks
🟢 AI-Infra / Hardware: Config search, placement under conflict constraints, hyperparameter enumeration

#28 Trie / prefix tree

O(L) per operation (L = word length)
Trigger: 'prefix queries','dictionary of words','autocomplete','search with wildcards'
Core Idea: Share prefixes to make prefix queries proportional to word length; enables DFS pruning
Structures: trie nodes (array or hash map per node) with end flags
🟢 AI-Infra / Hardware: Autocomplete, tokenizer vocabularies, longest-prefix-match routing

#29 DP (1D state design)

O(n * states_per_position)
Trigger: 'number of ways','min/max cost','can we reach target','decisions at each step'
Core Idea: Define state -> transition -> base case -> evaluation order -> answer location (in that exact order)
Structures: 1D array or hash map
🟢 AI-Infra / Hardware: Stage-wise cost optimisation, pipeline configuration selection

#30 DP (knapsack family)

O(n * capacity)
Trigger: 'subset sum','choose items under capacity budget','coin change','ways to make amount'
Core Idea: Capacity is a DP dimension; loop order encodes 0/1 (descending) vs unbounded (ascending)
Structures: 1D or 2D DP arrays
🟢 AI-Infra / Hardware: Memory/GPU packing, multi-resource quota allocation

#31 DP (two sequences)

O(mn) time, O(min(m,n)) space with rolling
Trigger: 'two strings','edit distance','common subsequence','interleaving'
Core Idea: dp[i][j] over prefixes of both sequences; derive transitions from the problem definition
Structures: 2D array or rolling 1D for space optimization
🟢 AI-Infra / Hardware: Diffing, log/sequence alignment, tokenizer alignment

#32 DP (interval)

O(n^3)
Trigger: 'optimal order of operations on a range','merge/burst/remove from a subarray'
Core Idea: Solve shorter ranges first; pick the LAST operation (not first) to keep subproblems independent
Structures: 2D DP array dp[left][right]
🟢 AI-Infra / Hardware: Optimal chunking, merge ordering, compaction cost minimisation

#33 DP (bitmask)

O(2^n | n) or O(2^n | n^2)
Trigger: 'n<=20','visit all nodes','assign items to groups','travelling salesman variant'
Core Idea: State includes a subset bitmask; transition adds one element; (mask, position) is the full state
Structures: dp[mask][...] arrays
🟢 AI-Infra / Hardware: Job-to-machine assignment, small-scale optimal placement

#34 DP optimization (deque/heap in transition)

O(n) or O(n log n)
Trigger: naive DP transition is O(nk) or O(n^2) and n>10^3
Core Idea: Optimize the transition by hiding a sliding-window maximum/minimum (monotonic deque) inside it
Structures: DP array + monotonic deque or heap or prefix max array
🟢 AI-Infra / Hardware: Streaming DP with bounded lookback; windowed online decisions

#35 Fenwick Tree (BIT)

O(log n) update/query
Trigger: 'mutable range sum','inversion count','point update + prefix query'
Core Idea: Lowest set bit (i & -i) tree decomposition; O(log n) update and query with tiny constant factor
Structures: 1D array (1-indexed)
🟢 AI-Infra / Hardware: High-frequency telemetry counters, rolling latency meters

#36 Segment Tree (range query)

O(n) build, O(log n) update/query
Trigger: 'range min/max/sum/gcd query','point or range updates'; associative function
Core Idea: Divide-and-conquer binary tree over array intervals; 4n array representation; lazy propagation
Structures: tree array, lazy array
🟢 AI-Infra / Hardware: Distributed SLA monitoring, physical memory reservation maps

#37 Tarjan's DFS (bridges & SCC)

O(V + E)
Trigger: 'critical connections','single point of failure','strongly connected components'
Core Idea: Discovery time tin[u] and lowest ancestor low[u]; back-edge detection; condensation DAG
Structures: tin array, low array, visited stack
🟢 AI-Infra / Hardware: Fault-domain isolation, deadlock detection, build dependency validation

#38 Hardware / Cache calibration

O(n) with 10x lower constant factor
Trigger: high throughput, 10M+ QPS, low latency SLO, memory-constrained traversal
Core Idea: Structure data contiguously (AOS vs SOA); eliminate pointer chasing; size blocks to L1/L2 cache
Structures: flat contiguous buffers, cyclic arrays
🟢 AI-Infra / Hardware: Tensor memory layouts, GPU shared memory tiling, low-latency trading

#39 High-performance hashing

O(1) average and worst-case
Trigger: zero tail-latency, low collision variance, predictable lookup time
Core Idea: Robin Hood displacement or Cuckoo two-table hashing; bounded worst-case probe lengths
Structures: flat key/value array + probe count byte
🟢 AI-Infra / Hardware: Storage engine block caches, Memcached, Redis hash tables

#40 Adaptive Cache (ARC)

O(1) per lookup and update
Trigger: dynamic workload with mixed scans and recurring loops; hit ratio optimization
Core Idea: Balance recency (T1) and frequency (T2) dynamically using ghost history lists (B1, B2)
Structures: 4 LRU lists (T1, T2, B1, B2) + hash map
🟢 AI-Infra / Hardware: Database buffer managers, kernel page caches, multi-tenant AI caching

#41 Lock-free ring buffer

O(1) wait-free SPSC / lock-free MPMC
Trigger: high-speed inter-thread message passing; zero lock contention; producer-consumer
Core Idea: Head and tail indices advancing monotonically; masking with (size - 1); cache line padding (64 bytes)
Structures: atomic size_t head, tail; contiguous array buffer
🟢 AI-Infra / Hardware: LMAX Disruptor, GPU command rings, high-throughput network packet ingestion

#42 HNSW graph search

O(log N) average query time
Trigger: approximate nearest neighbor (ANN), vector similarity, high dimensionality (d=128 to 1536)
Core Idea: Multi-layer proximity graph (skip-list concept); greedy routing on coarse upper layers, beam search on layer 0
Structures: layered adjacency list, candidate priority queue, visited set
🟢 AI-Infra / Hardware: Vector databases (Milvus, Pinecone, Qdrant, FAISS), RAG pipelines
