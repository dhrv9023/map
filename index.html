🎯 Interview Question — Python Async

Q: Explain the difference between asyncio.gather() and asyncio.create_task(). When would you use each?

Model Answer: gather() waits for all tasks and returns results in order. create_task() schedules a coroutine immediately and returns a Task object. Use gather() when you need results; use create_task() for fire-and-forget operations. Example: results = await asyncio.gather(*tasks) vs task = asyncio.create_task(coro()). Interviewers check if you understand event loop scheduling.

🎯 Interview Question — Linear Algebra

Q: Why is matrix multiplication not commutative? Give a practical example from ML.

Model Answer: A×B ≠ B×A because matrix dimensions must align: (m×n) × (n×p) = (m×p). In neural networks, layer order matters: input→W1→W2 is different from input→W2→W1. Practically, if you swap weight matrices in a transformer, you get garbage output. This shows you understand both math and its application.

🎯 Interview Question — Linux Debugging

Q: A Python service is consuming 100% CPU but not doing anything. How would you debug it?

Model Answer: (1) `top` or `htop` to see which process. (2) `strace -p ` to see system calls. (3) `perf record -p ` for profiling. (4) Check logs with `journalctl -u service-name`. (5) Use `gdb` to attach and see stack trace. This shows you know production debugging workflow.

Research Papers

The papers that built modern AI. Read them in order. Understand them deeply.

Why read papers? Every framework you use was built from a paper. When you understand the paper, you understand WHY the tool works, not just HOW to use it. In interviews at NVIDIA, Google, and OpenAI, you will be asked about papers. Engineers who've read the original papers answer with depth. 🧠 How to read a research paper (if you've never done it)

Pass 1 (10 min): Read title, abstract, conclusion, look at all figures. Get the big picture — what problem does it solve, what's the key idea, what are the results?

Pass 2 (30-45 min): Read introduction, related work, method section. Skip math you don't understand on first pass. Focus on: what did they do differently, why does it work?

Pass 3 (1-2 hours, only for critical papers): Read everything including math. Implement the key idea in code. This is how you truly understand a paper.

Rule: Not every paper needs Pass 3. Most need Pass 1+2. Only the 10-15 most critical papers (marked ★★★ below) need full implementation.
