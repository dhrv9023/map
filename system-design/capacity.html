📐 Little's Law in Model Serving Architecture
Little's Law is the universal mathematical bridge between QPS, response latency, and system concurrency: $$L = \lambda \times W$$ Where:
• $L$ = Average number of concurrent requests in the system.
• $\lambda$ = Arrival rate in Requests Per Second (RPS / QPS).
• $W$ = Average end-to-end response time / latency in seconds.

Worked Example: If your LLM serving API receives 200 QPS and each generation takes an average of 1.5 seconds ($W = 1.5$), the serving system must hold: $$L = 200 \times 1.5 = \mathbf{300\text{ concurrent active requests}}$$ Your GPU cluster must possess sufficient KV-cache memory to support 300 simultaneous active streams without dropping requests or triggering memory eviction.
